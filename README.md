# Bomb Game

Игра на Python и Tkinter для двух ноутбуков. Один игрок выбирает роль «Бомба», второй — «Кнопки». Игрок с пультом читает инструкцию и нажимает кнопки проводов, а состояние игры синхронизируется по UDP.

## Запуск

1. Установите Python 3.10 или новее.
2. Откройте терминал в папке `bomb_game`.
3. Запустите игру на каждом ноутбуке:

   ```bash
   python main.py
   ```

4. На одном ноутбуке выберите «Бомба», на другом — «Кнопки».
5. Разрешите Python обмениваться данными через брандмауэр Windows для частных сетей.

Оба ноутбука должны иметь сетевое соединение друг с другом. Игра использует UDP-порт `50000`.

## Структура проекта

- `main.py` — создание приложения и обработка игровых сетевых событий.
- `config.py` — настройки, цвета и тексты инструкций.
- `game/logic.py` — генерация серийного номера и проводов, игровые правила.
- `game/state.py` — состояние игры, таймер и обработка перерезания проводов.
- `network/network_manager.py` — обнаружение второго игрока и UDP-обмен.
- `ui/` — окна выбора роли, бомбы и пульта.
- `utils/resources.py` — пути к ресурсам и воспроизведение звуков.
- `assets/` — изображения, иконка и звуковые файлы.

## Зависимости

Tkinter обычно входит в установку Python. Pillow необязателен и используется для загрузки изображения взрывающейся кошки, если он установлен.
